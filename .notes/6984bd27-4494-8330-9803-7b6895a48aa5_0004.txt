📊 The Solution
Problem: 2.6-second GPU flush delays on X11 + Mesa + xfwm4

Root Cause: GPU threading contention between:

Firefox WebRender GPU thread
Mesa GL threading
X11 compositor synchronization
Multiple Firefox content processes
Solution: Reduce contention by:

Disabling redundant GPU threading layers
Reducing content process count from 8+ to 4
Controlling memory growth
Throttling background tabs
Result:

✅ Eliminated WaitFlushedEvent delays
✅ Reduced load average from 5.18 to 2.79
✅ Smooth scrolling and tab switching
✅ No functionality regressions
