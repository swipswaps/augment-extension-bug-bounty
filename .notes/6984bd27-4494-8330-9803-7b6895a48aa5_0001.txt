What those messages actually mean
1.

ATTENTION: default value of option mesa_glthread overridden by environment.

What this is

    mesa_glthread enables Mesa’s threaded OpenGL command submission.

    It can be set by:

        /etc/environment

        /etc/profile.d/*.sh

        distro defaults

        wrapper scripts (Flatpak, launchers)

Why it matters for Firefox

    Firefox uses OpenGL via EGL/GLX on X11 for compositing.

    Mesa’s GL threading is not always a win:

        On Intel iGPUs (especially pre-Xe or early Xe)

        On X11 compositors like xfwm4

        When Firefox already has its own render threads

Result: extra synchronization → more stalls.
2.

[GFX1-]: Calling WaitFlushedEvent::Run: is delayed: 2593

This is the big red flag.

Firefox’s render pipeline is waiting ~2.6 seconds for the GPU/X server to acknowledge flushed commands.

This usually means one or more of:

    GPU command queue congestion (OpenGL + Xorg)

    CPU pressure delaying the compositor thread

    Memory pressure causing paging delays

    Bad interaction between:

        Firefox WebRender

        Mesa GL threading

        Xorg + xfwm4

Mozilla-recommended approach for X11 systems:

    Keep WebRender enabled, but calm it down

    Disable unnecessary GPU threading

    Reduce process fan-out

    Reduce memory pressure to avoid swap

    Avoid forcing exotic backends (no VAAPI hacks here)

// ============================================================================
// Firefox X11 + Mesa + XFCE performance tuning
// Informed by Mozilla docs, Mesa behavior, and real-world Linux profiling
// ============================================================================

// ---------------------------------------------------------------------------
// PROCESS & THREAD CONTROL
// ---------------------------------------------------------------------------

// Reduce content process explosion (default can be 8+)
user_pref("dom.ipc.processCount", 4);
user_pref("dom.ipc.processCount.web", 4);

// Prevent runaway background processes
user_pref("dom.ipc.keepProcessesAlive.web", 1);

// ---------------------------------------------------------------------------
// GRAPHICS PIPELINE (X11 SAFE SETTINGS)
// ---------------------------------------------------------------------------

// Keep WebRender enabled (better than old layers)
user_pref("gfx.webrender.all", true);

// Avoid forcing software or exotic paths
user_pref("gfx.webrender.force-disabled", false);

// Disable GPU thread that often stalls on Mesa + X11
user_pref("gfx.webrender.enable-gpu-thread", false);

// Avoid over-aggressive frame scheduling
user_pref("gfx.webrender.compositor", true);

// Disable GL fencing that can cause long waits
user_pref("gfx.webrender.wait-for-gpu", false);

// Prevent Firefox from second-guessing Mesa threading
user_pref("gfx.x11-egl.force-enabled", true);
user_pref("gfx.x11-egl.force-disabled", false);

// ---------------------------------------------------------------------------
// OPENGL / MESA INTERACTION
// ---------------------------------------------------------------------------

// Let Mesa decide threading instead of Firefox assumptions
user_pref("gfx.gl.early-init", false);

// Avoid extra GL worker threads
user_pref("gfx.gl.multithreaded", false);

// ---------------------------------------------------------------------------
// MEMORY PRESSURE & SWAP AVOIDANCE
// ---------------------------------------------------------------------------

// Lower JS memory pressure to reduce swap hits
user_pref("javascript.options.mem.max", 4096);
user_pref("javascript.options.mem.high_water_mark", 2048);

// Encourage faster GC under pressure
user_pref("javascript.options.gc_delay", 2000);

// Reduce retained decoded image cache
user_pref("image.mem.decode_bytes_at_a_time", 32768);
user_pref("image.mem.shared.unmap.min_expiration_ms", 30000);

// Limit media cache size
user_pref("media.memory_cache_max_size", 65536);

// ---------------------------------------------------------------------------
// TAB & BACKGROUND BEHAVIOR
// ---------------------------------------------------------------------------

// Throttle background tabs more aggressively
user_pref("dom.min_background_timeout_value", 1000);
user_pref("dom.timeout.background_throttling_max_budget", 5000);

// Suspend inactive tabs earlier
user_pref("browser.tabs.min_inactive_duration_before_unload", 300000);

// ---------------------------------------------------------------------------
// DISK I/O & CACHE
// ---------------------------------------------------------------------------

// Reduce disk cache thrash
user_pref("browser.cache.disk.enable", true);
user_pref("browser.cache.disk.capacity", 262144); // 256 MB

// Avoid constant cache writes
user_pref("browser.cache.disk.smart_size.enabled", false);

// ---------------------------------------------------------------------------
// TELEMETRY / BACKGROUND NOISE (PERF-NEUTRAL BUT HELPFUL)
// ---------------------------------------------------------------------------

user_pref("toolkit.telemetry.enabled", false);
user_pref("toolkit.telemetry.unified", false);
user_pref("datareporting.healthreport.uploadEnabled", false);

// ============================================================================
// END OF FILE
// ============================================================================
